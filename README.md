# Todo List App

Welcome to the Todo List App! 🎉 This is a sleek and intuitive task management application built with React. It leverages modern React hooks like `useState`, `useEffect`, and `useContext`, providing a seamless experience for managing your daily tasks.

## Overview

The Todo List app is designed to help users efficiently organize their tasks. With features like adding, editing, and deleting tasks, you can easily keep track of what needs to be done. Plus, thanks to local storage, your tasks will persist even after refreshing the page!

## Features

- **Add Todos**: Quickly add new tasks to your list with a simple input.
- **Edit Todos**: Modify existing tasks to reflect any changes.
- **Delete Todos**: Remove tasks that are no longer relevant.
- **Toggle Completion**: Mark tasks as complete or incomplete to manage your progress.
- **Data Persistence**: All tasks are saved in the browser's local storage, ensuring they remain accessible after page refresh.
- **Context API**: Uses the Context API to manage state across components, simplifying data flow.

## Technologies Used

- **React**: The core library for building user interfaces.
- **JavaScript (ES6+)**: Modern JavaScript features for cleaner and more efficient code.
- **Tailwind CSS**: A utility-first CSS framework for styling the application.
